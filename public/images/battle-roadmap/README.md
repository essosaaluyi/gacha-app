# Battle Progress Glass Tube Assets

Premium glass-tube battle progress UI for the top of the battle screen above the enemy counter.

- `battle-progress-roadmap-10.svg` - full static 10-station reference bar.
- `battle-progress-track.svg` - empty segmented glass tube base for dynamic implementation.
- `station-cleared.svg` - completed station.
- `station-current.svg` - active liquid station with restrained cyan/purple gloss.
- `station-upcoming.svg` - inactive future station.
- `station-boss.svg` - final station marker.

Recommended placement: top center of the battle HUD, same area as the current bead progress bar. Use 10 total stations and drive state from current battle round/stage.
