# カードテーブル3D：貼り込みテクスチャ素材仕様

対象：`lib/table-3d/cabinetTable3D.ts`（three.js のカードテーブル）
素材制作：Codex ／ 実装：Claude ／ 起案：2026-11-13

## 0. この方式が何か

テーブルのライト計算をやめ、**絵をそのまま貼る**（three.js の `MeshBasicMaterial`、`toneMapped: false`）。
テクスチャの1pxが画面の1pxになるので、原画の色がそのまま出る。影も陰影もテクスチャに描き込んでおく。
見た目は2Dのまま、めくり・回転は3Dとして動く。

Blender のベイク運用と同じ考え方で、順序が逆になる点が重要：
**絵が先、メッシュが絵に合わせる。** テーブルの形は原画から逆投影して作ってあるので、すでにその状態にある。

## 1. 素材は2種類に分かれる

| 種類 | 何か | UV | 例 |
|---|---|---|---|
| **面マップ** | その面を真正面から見た1枚絵 | world 座標そのまま | 天板、井戸の底、板の裏 |
| **断面ストリップ** | 断面を横に引き延ばした帯。長さ方向にタイリング | u=長さ方向、v=断面方向 | 外周の縁、ベイ枠、井戸の壁 |

断面ストリップは、長さ方向の明暗（原画は奥が明るく手前が暗い）を含めない。
そこは Claude 側が頂点カラーで原画から掛ける。**ストリップは奥でも手前でも同じ絵にする。**

## 2. 共通ルール

- **遠近をつけない。** 真正面（面マップ）または断面を正対（ストリップ）で描く。
- **陰影・映り込み・エッジのハイライトは描き込む。** ライトは一切効かない。
- 基準密度 **512 px = world 1.0**（原画の実効密度は横390px・縦248px相当なので2倍前後の余裕がある）。
- 色空間 sRGB。原画 `/images/cabinet/production/card-table-premium-three-bay-center-only-1120x420.webp` と同じトーンに合わせる。
- アルファは**天板のみ**必要（ベイ開口3か所を抜く）。他は不透明。
- ストリップは**横方向にシームレス**（左右の端がつながる）。
- 形式 WebP。Safari で表示できる形式のみ。
- 置き場所 `public/images/cabinet/table3d/`。ファイル名は**必ずバージョン付き**（`*.v1.webp`）。本番は `public/` に1年の immutable キャッシュが付くため、同名上書きは禁止。

## 3. 必要な素材

### 3-1. 天板（面マップ・任意）

| | |
|---|---|
| ファイル | `table-top.v1.webp` |
| 寸法 | **1384 × 480 px** |
| カバー範囲 | world X −1.3512〜1.3512、Z 0.1119〜1.0485（2.7023 × 0.9367） |
| 内容 | テーブル上面を真上から。外周の真鍮縁、フェルト、ベイ枠3つを含む。ベイ開口3か所はアルファ0で抜く。 |

**これは任意。** 原画から逆投影して自動生成できる（Claude 側で実施予定）。
逆投影だと奥側だけ縦1.5倍・横1.27倍ぼけるので、**奥の解像感を上げたい場合のみ**描き直してもらう。

|---|---|

| 内容 | v=0（上端）がフェルト側、v=1（下端）がスカートの底。上から順に：真鍮のベベル、真鍮の平面、角の落ち、前面の厚み、その下の暗いスカート。 |

テーブル外周（周長 world 7.06）を14周ほどタイリングする。横方向の明暗は入れない。

**ここが今いちばん原画と差が出ているところ。** 細い金線と面取りの光を、絵として描いてほしい。

### 3-4. 井戸（ベイの中）の内壁（必須）

| | |
|---|---|
| ファイル | `bay-well-walls.v1.webp` |
| 寸法 | **1024 × 144 px** |
| 内容 | 4枚の壁を左から順に1枚の画像に並べる：**奥壁 → 右壁 → 手前壁 → 左壁**。 |
| 各壁の幅 | 奥・手前 world 0.4512（=256px）、左右 world 0.4480（=254px） |
| 壁の深さ | world 0.26（=133px、画像の上端が天板の高さ、下端が井戸の底） |

カードが落ちた先・めくった瞬間に見える。手前壁には留め具（world 幅0.155・厚0.012）が付くので、
その影を描き込んでよい。全体に暗い（原画のスロット内側は `#0d1a1b` 相当）。3ベイ共通で使う。

## 4. 容量

全部合わせて GPU 上で約 5.6 MB（ミップマップ込みで約 7.5 MB）。
仕様書の上限 8 MiB に収まるが余裕は少ない。重い場合は 3-6 を 512→256 に落とす。

## 5. 受け入れ条件

1. 静止状態のテーブルが、原画と並べて**どちらが絵か分からない**。
2. ベイ枠の金のヘアラインが、原画と同じ太さ・明るさで見える。
3. スロットをめくったとき、井戸の内壁と板の裏に「描かれていない面」が出ない。
4. ライトを全部消しても見た目が変わらない（＝ライトに依存していない）。

## 6. 実装側の責任（Claude）

- 天板の逆投影生成、UV の割り当て、ストリップのタイリング回数。
- 長さ方向の明暗（原画の奥明るい／手前暗い）を頂点カラーで掛ける。
- 回転中の板だけ、必要ならわずかに暗くする処理（完全無灯だと「絵が回る」感じになるため）。
- スロット四隅・カメラは変更しない。
