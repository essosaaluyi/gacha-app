# ドッグ専用 Seedance制作手順

「ドッグ｜Seedanceの絵コンテ・プロンプト」で演出を新規提案・改訂するときに、このファイルの最新版を読む。案件ごとのオーナー指示を優先する。

## 1. 実作品を調べ、4案のラフを比較する

- 依頼から、観客に何を感じさせたいか、何が画面で読める必要があるか、前後の画面にどうつなぐかを整理する。尺や画面比率を仮置きした場合は明記する。
- まず公式ゲームPV、アニメPV、制作会社の公開映像から探す。構図・画角・光は [ShotDeck](https://shotdeck.com/) と [Pinterest](https://www.pinterest.com/)、CMやモーションのテンポは [STASH](https://vimeo.com/channels/stashmagazine) で必要に応じて補う。ピンからは可能な範囲で元作品をたどる。
- A〜Dの4案を、同じ画面比率の **4案×3コマのラフ比較シート1枚**にまとめる。シルエットで人物の配置、視線、動き、カメラの位置と移動が読めるようにする。カメラの高さや距離、溜め、着弾や反応、前後のつなぎ方を変えて、選択に意味のある差を作る。
- 各案に判断に効く実作品の参照を原則1点添える。作品名、元のリンク、動画なら確認した秒数、画面のどの要素をどう使うかを書く。構図の議論には参照静止画、動きの議論には該当箇所の動画リンクを優先する。閲覧できなかった箇所や仮説は明記し、未確認の秒数は記載しない。
- 各案の見せ場とトレードオフを短く添え、オーナーが案を選ぶか、案の要素を組み合わせられる状態でレビューに出す。

## 2. 選んだ方向を詰める

選択とフィードバックを反映した修正版を出す。コマごとの尺、カメラ、動き、開始・終了画を詰める。つながりやテンポの判断が難しい場合は、ラフを秒数どおりに並べた簡易動画を使う。

## 3. 承認後にSeedance用へ展開する

修正版の承認後、必要な参照素材とショット単位のSeedanceプロンプトを作る。承認済みキャラの顔、衣装、シルエットと、合意した構図・尺・前後のつながりを照合する。

## 運用の見直し

案件ごとに、判断に役立ったラフや参照、手戻りの原因を短く残す。複数の案件にも効く変更はオーナーと合意して、このファイルに反映する。
